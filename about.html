ABOUT / DEVTRACK

A little structure.
A lot of possibility.

A project planner built for developers who want to keep moving.

One workspace, five views

DevTrack brings project planning and task tracking together. Create projects, add tasks, and use your dashboard to review progress. Search and filters help you focus on the work that matters now.

Your data stays in your browser

Projects and tasks are saved automatically on this device. There is no account or cloud sync. Clearing browser data removes your workspace; another device or browser has its own workspace.

Built with the fundamentals

This Web Technologies synthesis project uses semantic HTML, responsive CSS, and vanilla JavaScript. Forms, browser validation, events, arrays, objects, DOM updates, and localStorage work together without a framework.
