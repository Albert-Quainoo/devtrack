# DevTrack

A project and task planner built with HTML, CSS, and JavaScript.

[Live app](https://albert-quainoo.github.io/devtrack/)

- Create, edit, delete, search, and filter projects.
- Add tasks, set priorities, and track completion.
- View progress on the dashboard.

Data is saved in this browser using localStorage. There is no account or cloud sync.

**Run locally:** `python3 -m http.server 8000`, then open http://localhost:8000.

**Tests:** `npm test` (requires Node.js).

See [DEPLOYMENT.md](DEPLOYMENT.md) for hosting instructions.
